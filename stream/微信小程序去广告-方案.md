## 一、抓包分析结论

共 7 个请求,全部来自同一个小程序 **appid `wx3685801519731c2e`**(Referer 均为 `servicewechat.com/wx3685801519731c2e/267/page-frame.html`)。

| 请求 | 域名 | URL 特征 | 响应 | 可否精确拦截 |
|---|---|---|---|---|
| 视频广告 ×1 | `wxsmw.wxs.qq.com/snssvpdownload/` | 文件名 `ads_svp_video__...mp4` | video/mp4 | ✅ 特征明确 |
| 图片广告 ×6 | `wximg.wxs.qq.com/snscosdownload/` | 随机 32 位哈希(+ `_dGltYWdl_` 后缀) | image/jpeg,png | ❌ 无特征 |

- `_dGltYWdl_` 是 base64 编码的 `image`,微信 CDN 图片处理标记,非广告标记。
- MITM 解密成功(body 为明文 JPEG/MP4),证书已装可解密。

## 二、域名判断

`wximg.wxs.qq.com` / `wxsmw.wxs.qq.com` 为**微信通用内容 CDN**,非广告专用:
- `snssvpdownload` = SNS 视频下载(朋友圈视频、小程序视频、广告视频共用)
- `snscosdownload` = SNS 图片下载(朋友圈图片、头像、小程序图片、广告图片共用)

**禁止整域名 REJECT**,会误伤朋友圈等正常内容。

## 三、关键判断:广告类型

抓到的广告走 `wxs.qq.com` 微信官方 CDN → **微信流量主广告组件**(微信统一分发)。
- 广告数据 API 走微信内部通道,**大概率抓不到**。
- 能抓到的只有 CDN 内容下载,而 CDN 域名又与朋友圈共用。
- 无现成模块可参考(通用规则集如秋风/AWAvenue 不含此内容)。

## 四、案例模块参考(ddgksf2013 Applet)

见 `stream/案例.md`。思路:**逐个拦截小程序自建广告 API**(便利蜂 banner、顺丰 info-flow-adver、公众号 getappmsgad)。
**不适用于本场景**:本场景广告走微信官方 CDN,非小程序自建域名。

## 四·补、GrandpaNiu 仓库调研(2026-08-08)

仓库 `https://github.com/GrandpaNiuu/GrandpaNiu`(已浅克隆到临时目录分析)。

三个微信相关模块:
- `wechat.sgmodule`:`DOMAIN-SUFFIX,wxs.qq.com,REJECT` 整域名拦 → **被自己证伪**
- `wechat-mini-programs.sgmodule`:逐小程序拦广告 API(URL Rewrite + Body Rewrite jq + http-response 脚本),覆盖便利蜂/顺丰/美团/12306 等几十个小程序
- 主融合 `Ronghemokuai.sgmodule`:只 REJECT 朋友圈视频子域 `wxsnsdy/wxsmsdy/wxsnsdythumb.wxs.qq.com`;`direct.list` 第 27 行把 `wxs.qq.com` 设为 `DIRECT,pre-matching` 安全直连保护

**关键结论**:
1. 该仓库自己踩过"微信不能发图、朋友圈图片加载失败"的坑(见 `reports/media_wechat_false_positive_report.md`),修复 = 把 `wxs.qq.com` 整体加入 DIRECT 保护链 → **整域名拦 wxs.qq.com 被实测证伪**
2. 我们抓的 `wximg.wxs.qq.com`/`wxsmw.wxs.qq.com`(微信官方小程序广告 CDN)**GrandpaNiu 未拦**,且在 DIRECT 保护内
3. 印证方向 A(`ads_svp_video` 特征)是唯一不误伤朋友圈的精确抓手

## 五、可行方向

### 方向 A:拦截视频广告(立即可做)
```
[URL Rewrite]
^https://wxsmw\.wxs\.qq\.com/.*snssvpdownload/.*ads_svp_video - reject-200
```
精确、通用(所有小程序的 `ads_svp_video` 视频广告均有效)。仅解决视频。

### 方向 B:按 appid 拦截 CDN 图片(http-request 脚本)
```
[Script]
weixin_ads_img = type=http-request, pattern=^https://wximg\.wxs\.qq\.com/snscosdownload/, script-path=...weixin-ads.js
```
脚本:Referer 含 `wx3685801519731c2e` → reject。
**前提**:该小程序除广告外几乎无正常图片。若含商品图/头像/内容图会被误伤。

### 方向 C:治本 — 补抓广告 API(参考案例模块)
重新抓包打开广告页面,找返回 JSON 的广告数据接口再拦。
**风险**:微信官方广告组件数据走内部加密通道,可能抓不到。

## 七、pyq(朋友圈)广告说明

朋友圈广告与本次抓包**同一套 CDN**:
- 视频广告(带 `ads_svp_video` 特征)→ 模块可拦
- 图片广告(哈希 URL)→ 无法与正常图片区分,模块**拦不了**

## 八、接入执行步骤(确认后按场景一)

1. 定模块名、拦截范围
2. `[URL Rewrite]` 段加 BEGIN/END 区块(方向 A),如启用方向 B 再加 `[Script]` 区块
3. `[MITM]` 用 `%APPEND%` 合并 `wxsmw.wxs.qq.com`、`wximg.wxs.qq.com`(保持单行)

5. `sources/` 归档,标注 `# type: manual`

## 九、抓包验证结果(2026-08-08,HAR `11"42"09.har`,87 请求)

### 验证结论:方案可行,且发现治本抓手

**发现 1 — 自建广告配置接口(治本 ✅)**
- `aster.yuxiaor.com/config/aster-home-public-ad-config-v2.json` 返回完整广告位配置
- `data.ads` 含 `fallbackAd`(首页兜底,status=1)、`fliggy`(飞猪,status=1)、`bianminzhaohuoba`/`didiLivpet`(status=0 停用)
- 广告图走自建域 `aster.yuxiaor.com/appimg/*.png`
- **拦截此接口即治本**:自建广告位无配置不展示,精确、零副作用、不碰微信 CDN
- `aster-ad-config-v2.json` 当前 `data` 为空,同样拦上作防御

**发现 2 — 流量主视频广告(精确 ✅)**
- 6/6 个 `wxsmw.wxs.qq.com/snssvpdownload/ads_svp_video__*.mp4` 全部稳定带 `ads_svp_video__` 前缀
- 特征 100% 稳定,通用(所有小程序的微信流量主视频广告)

**发现 3 — 流量主图片广告(仍无 URL 特征 ⚠️)**
- `wximg.wxs.qq.com/snscosdownload/` 哈希 URL,无 ads 特征
- `posid=5060180989186180` 参数带/不带混杂,不可作特征
- 仅能按 appid(`wx3685801519731c2e`)+ Referer 拦截(http-request 脚本)

**其他发现**
- `api.yuxiaor.com` 为纯业务数据(城市/合同/工单),**非广告源**
- `wxa.wxs.qq.com/images/wxapp/*.png` 为小程序 UI 图标,**非广告**
- `mmbiz.qpic.cn` 16 张小图(1-13KB)性质待确认,可能是广告角标或正常分享图
- `res.wx.qq.com/op_res/` 为微信系统资源
- 小程序正常静态资源走自建域 `apart.yuxiaor.com`(见 `/tapp/v1/settings/domain`),**不走 wximg CDN**

### 最终推荐方案

```
[URL Rewrite]
# ① 自建广告配置接口(治本,精确)
^https://aster\.yuxiaor\.com/config/aster-(home-public-)?ad-config-v2\.json.* - reject-200
# ② 微信流量主视频广告(通用,精确)
^https://wxsmw\.wxs\.qq\.com/.*snssvpdownload/.*ads_svp_video - reject-200

[Script]
# ③ 可选:流量主图片广告,按 appid 拦(需确认小程序无正常 wximg 图片)
weixin_ads_img = type=http-request, pattern=^https://wximg\.wxs\.qq\.com/snscosdownload/, script-path=.../weixin-ads-img.js

[MITM]
hostname = %APPEND% aster.yuxiaor.com, wxsmw.wxs.qq.com, wximg.wxs.qq.com
```

分档:
- **保守档**:仅 ①(MITM 只加 `aster.yuxiaor.com`),去自建广告,零风险
- **标准档**:① + ②(MITM 加 `wxsmw.wxs.qq.com`),去自建广告 + 流量主视频
- **激进档**:① + ② + ③(加 `wximg.wxs.qq.com` + 脚本),连流量主图片也去,需实测误伤
